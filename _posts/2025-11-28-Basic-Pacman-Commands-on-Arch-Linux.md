## Main points

Update all packages:
```bash
sudo pacman -Syu
```

Force refresh package databases and update:
```bash
sudo pacman -Syyu
```

Update a specific package:
```bash
sudo pacman -S package_name
```

Search for an installed package by string:
```bash
pacman -Qs string
```
